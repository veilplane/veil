veil packages

Packages and repository metadata are signed with this key. Source and releases: github.com/veilplane/veil.

In one step

Adds the repository below (apt or dnf), installs veil and joins the node:

curl -fsSL https://packages.veilplane.com/install.sh | sudo sh -s -- join <join code>

Or -- try for a trial cluster without an account, or no arguments to install only.

Debian, Ubuntu

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/veil.asc https://packages.veilplane.com/veil-packages.asc
echo "deb [signed-by=/etc/apt/keyrings/veil.asc] https://packages.veilplane.com/deb ./" | sudo tee /etc/apt/sources.list.d/veil.list
sudo apt update && sudo apt install veil

Fedora, RHEL, Rocky, Alma

sudo curl -fsSLo /etc/yum.repos.d/veil.repo https://packages.veilplane.com/rpm/veil.repo
sudo dnf install veil

Then put the agent's configuration in /etc/veil/agent.json and run sudo systemctl enable --now veil.

veilctl

Veilplane from the terminal (organizations, clusters, nodes, API tokens), from the same repository: sudo apt install veilctl or sudo dnf install veilctl, then veilctl login. For macOS and Windows: the binaries of the latest release.
